# JAVA-LEARNING
Este repositório documenta minha evolução em Java, reunindo exercícios e projetos desenvolvidos continuamente com foco no aprofundamento de conceitos e boas práticas de programação.

## 📚 O que aprendi


### 🧱 Fundamentos
- Lógica básica em Java
- Sintaxe
- Estruturas:
  - Sequencial
  - Condicional
  - Repetitiva

### ⚙️ Conceitos de Programação
- Operadores Bitwise
- Comportamento de memória
- Arrays e Listas
- Manipulação de datas (Date / LocalDate)

### 🧩 Programação Orientada a Objetos (POO)
- Construtores
- Encapsulamento
- Sobrecarga
- Herança e Polimorfismo
- Enums e Composição

### 🚀 Avançado
- Tratamento de exceções
- Generics, Set, Map
- Programação funcional
- Expressões Lambda
- JDBC

### 🌐 Desenvolvimento
- Web services com Spring Boot e JPA 
- Interface gráfica com JavaFX

> Aviso: Este é um repositório de aprendizado. Alguns exercícios utilizam arquivos locais e podem exigir a criação de arquivos de teste ou a adaptação dos caminhos dos arquivos para funcionar corretamente.

### STATUS - Projeto `java-learning` foi concluído.
Este projeto foi iniciado em **5 de abril de 2026** e finalizado em **5 de outubro de 2026**. Desenvolvido ao longo de aproximadamente 6 meses para consolidar meus estudos e práticas em Java.
